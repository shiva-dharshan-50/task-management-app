# Project Context — Real-Time Task Management / Collaboration App

I am building a serious portfolio project by myself to strengthen my resume as an Angular developer with 1+ years of professional experience.

## Project

Build a **Real-Time Task Management / Collaboration Application** similar in concept to a simplified Jira/Trello.

The goal is NOT to create a basic tutorial CRUD application. I want this to look and behave like a real-world, production-style application that I can confidently explain in interviews and showcase on my resume/GitHub.

## Core Application Concept

Users can:

1. Register and log in
2. Create projects
3. Join/access projects
4. Create task boards
5. Create columns such as:

   * TODO
   * IN PROGRESS
   * REVIEW
   * DONE
6. Create tasks
7. Assign tasks to users
8. Set priorities
9. Set due dates
10. Add descriptions
11. Add comments
12. Move tasks between columns
13. Drag and drop tasks
14. See task changes in real time
15. Receive notifications
16. Search/filter/sort tasks
17. View project/task statistics
18. Manage their profile
